# Week 2 - Day 1
I solved 2 problems given for Week 2 day 1 dsa homework
## Problems Solved
### 1.Valid Anagram
Uses the frequency count approach in string in this problem while increasing the character frequency of the first string in the freq array and simultaneously decreasing the frequency of the character in second string one by one .finally checking if the frquency array counts are = 0.

Time Complexity: O(n)
Space Complexity: O(1)
### 2.First Unique Character in a String
It has the same approach as the first problem while incrementing count of each character in string and checking the first character in string to have count=1.

Time Complexity: O(n)
Space Complexity: O(1)
