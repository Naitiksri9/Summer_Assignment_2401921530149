# Week 1 - Day 2
Today I solved 3 problems based on Arrays, Hashing and Sliding Window.
## Problems Solved
### 1. Maximum Subarray
Using Kadane's Algorithm Found the maximum sum of a contiguous subarray.

Time Complexity: O(n)
Space Complexity: O(1)

### 2. Contains Duplicate
Sorted the array and checked adjacent elements If two consecutive elements were equal then returned true.

Time Complexity: O(n log n)
Space Complexity: O(1)

### 3. Maximum Average Subarray I
Maintained the sum of a fixed-size window and updated the maximum sum.

Time Complexity: O(n)
Space Complexity: O(1)
