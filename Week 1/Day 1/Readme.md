# Week 1 - Day 1

I solved the 3 problems given for day 1 dsa homework

## Problems Solved
### 1. Two Sum
I used the brute force approach to check every possible pairs equaling the target sum.

Time Complexity: O(n²)
Space Complexity: O(1)

### 2. Remove Duplicates from Sorted Array
Stored Unique elements at the start of the array and gave the size of the modified array as index+1 of last checked element.

Time Complexity: O(n)
Space Complexity: O(1)

### 3. Best Time to Buy and Sell Stock
Kept a minimal stock price stored and traversed the array while calculating the maximum profit 

Time Complexity: O(n)
Space Complexity: O(1)
