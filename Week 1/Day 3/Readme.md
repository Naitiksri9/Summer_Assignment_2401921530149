## Problems Solved
### 1.Move Zeroes
Using two pointers-Used a pointer to first move non zero elements to front and then changing all elements moved to zero using second pointer.

Time Complexity: O(n)
Space Complexity: O(1)
### 2.Container With Most Water
Used two parameters as length and height of the array and found the height to be minimum of two elements and and the length between them through which maximum area is found.two pointers at beginning and end respectively are incremented and decremented respectively according to the conditions.

Time Complexity: O(n)
Space Complexity: O(1)
